# 定投账本

比特币定投记账工具。

**https://bwy999.github.io/DCA/**

---

## 功能

**记账**
每笔定投填两个数，第三个自动算出。手续费含在到账数量里，不用单独记。

**持仓**
累计 BTC 数量、持仓均价、当前市值（美元 / 人民币 / BTC 三个口径同时显示）。

**收益**
浮动盈亏、收益率、按真实现金流计算的年化 IRR，可在人民币本位与美元本位之间切换。

**图表**
- 累计 BTC — 每级台阶是一笔定投
- 成本 / 市值 — 累计投入对持仓市值
- 买入分布 — 每笔买在什么价位

**其他**
行情与汇率自动获取、定投节奏提示、深浅主题、数据导出为 JSON 或 CSV、可安装到手机主屏幕。

单个 HTML 文件，无后端，数据只存在本地浏览器。
